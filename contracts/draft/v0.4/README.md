## Contract notes recorded in S0

- C15 has two paths (`/accept`, `/decline`), so `api/composer.v0.4.json` lists two route entries with id `C15`. C08 and C17 carry `expected_revision` / `expected_version` in the query string.
- Envelope-level reason codes (`envelope_*`, `bounds_extent_limit`) are S0 draft codes: plan X.2.1 names only the GLB codes and `raw_capture_not_accepted`.
- A home envelope draft may send `asset_id: null` (the scene id is assigned at first finalize); object drafts carry the existing `object_id`.
- ID prefixes not in the X.1 table (`evd_`, `vln_`, `lnk_`, `bnd_`, `cor_`) appear only in examples; loops may choose their own and record it.
- The lifecycle transition table adds internal events (`prepare_rejected`, `finish_succeeded`, `finish_failed`, `runtime_failed`) next to the method names.
- Corrections are made only by the integration-check step, as a new `v0.4.1` set copied to every repository, never an in-place edit.
