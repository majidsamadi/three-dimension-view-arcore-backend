# Home Scanner Service — backend

This repository is the planned backend for the independent Home Scanner platform. It is not Google ARCore or a Google service.

**Status: requirements baseline only; application implementation and AWS deployment are not delivered by this documentation.**

The initial commit establishes the default branch so the detailed requirements can be delivered through a documentation branch and pull request.
